# Tool User Guide Design Gallery

Ten responsive setup-guide layouts in one interactive gallery.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages

Every push to `main` runs the included deployment workflow. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions** once. The published site will be available at:

`https://jrkece.github.io/test-page/`
